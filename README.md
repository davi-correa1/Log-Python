## About the code:

* ### app.py :
Run the "app.py" to choose a password and confirm it right away. If the password is wrong, a log will be sent to the file "app.log".

* ### app.log :
This file recives the logs that the 'app.py' sends. These logs can be a notification to say that the client is on, or that the password is wrong.

* ### alarm.py : 
This file is responsible for reading the 'app.log' and reporting any threats.
